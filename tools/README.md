# Инструменты разработки

- `extract_ru.py` → `ru_keys.txt`: строки интерфейса для перевода; `uz*.tsv`, `extra_uz.tsv` — переводы; `build_i18n.py` собирает `static/i18n.js` и `hq/templates/i18n.js` из `i18n_runtime.js`.
- `load_gen.py`, `load_bench.py` — нагрузочный тест Центра (docs/LOAD.md).

На кассы эта папка не попадает.
